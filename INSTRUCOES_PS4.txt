🎮 CONFIGURAR PKGi NO PS4
==========================

📋 URLs para usar no FPKGi:

Games:    http://192.168.15.6:8080/GAMES.json
DLC:      http://192.168.15.6:8080/DLC.json
Homebrew: http://192.168.15.6:8080/HOMEBREW.json

🔧 PASSOS NO PS4:

1. Abra o FPKGi
2. Aperte o botão TRIÂNGULO (△) 
3. Vá em "Settings"
4. Vá em "Content URLs"
5. Configure:
   - Games URL: http://192.168.15.6:8080/GAMES.json
   - Apps URL: http://192.168.15.6:8080/GAMES.json  
   - DLC URL: http://192.168.15.6:8080/DLC.json
   - Homebrew URL: http://192.168.15.6:8080/HOMEBREW.json

6. Pressione X para salvar
7. Pressione CÍRCULO (○) para voltar
8. Pressione R1 para atualizar a lista

✅ VERIFICAÇÃO:
- Se aparecer "Loading..." e depois uma lista de jogos, está funcionando
- Se não carregar, verifique se o servidor está rodando no PC
- Certifique-se que PS4 e PC estão na mesma rede WiFi

❌ PROBLEMAS COMUNS:
- Lista vazia: Verifique se o servidor está rodando
- Erro de conexão: Verifique o IP (deve ser 192.168.15.6)
- Downloads lentos: Normal, depende da internet
