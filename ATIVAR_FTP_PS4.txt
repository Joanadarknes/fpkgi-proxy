🎮 COMO ATIVAR FTP NO PS4
==========================

📋 PASSOS PARA ATIVAR FTP:

1. 🔓 JAILBREAK NECESSÁRIO:
   - PS4 deve estar com CFW/HEN ativado
   - Firmware 9.00 ou inferior

2. 🌐 ATIVAR FTP:
   Opção A - Via FTP App:
   - Instale "FTP Server" do homebrew
   - Execute o app
   - Anote o IP e porta mostrados

   Opção B - Via WebUI:
   - Acesse o menu do HEN/CFW
   - Procure por "FTP Server" 
   - Ative o servidor FTP

3. 🔗 TESTAR CONEXÃO:
   - IP do PS4: 192.168.15.3 (exemplo)
   - Porta: 1337 ou 2121
   - Usuário: anonymous (sem senha)

===============================

🚀 SCRIPT AUTOMÁTICO:
Depois de ativar o FTP, rode:
python config_automatico_ps4.py

===============================

⚙️ CONFIGURAÇÃO MANUAL:
Se o script não funcionar:

1. Use qualquer cliente FTP
2. Conecte no PS4
3. Vá para: /user/data/FPKGi/
4. Envie o arquivo: config_ps4.json
5. Renomeie para: fpkgi.json

===============================

🔍 VERIFICAÇÃO:
Após configurar, no FPKGi:
- Aperte △ (menu)
- Settings > Content URLs
- Verifique se os URLs estão corretos
- Reinicie o app
