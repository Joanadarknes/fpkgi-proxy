LOJA PKGI PS4 - LAUNCHER PKG

URL que o launcher abre:
https://joanadarknes.github.io/LojaPKGI/

Arquivos preparados:
- pkg-source/index.html
- pkg-source/sce_sys/icon0.png
- pkg-source/sce_sys/param.sfo
- PS4GamesStore.gp4
- pkg-source.gp4

Observacao importante:
Este projeto contem a fonte do launcher, mas esta maquina nao tem as ferramentas PS4 fPKG instaladas para compilar um .pkg executavel final.

Para gerar o PKG:
1. Abra o arquivo GP4 em uma ferramenta PS4 fPKG/GP4 compativel.
2. Gere o pacote a partir dos arquivos em pkg-source.
3. Instale o PKG no PS4 com seu instalador de homebrew/fPKG.

O PKG sera apenas um launcher/atalho para abrir a pagina online da loja.
